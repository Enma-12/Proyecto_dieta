# Proyecto_dieta

# 🥗 Sistema de Optimización de Costos de Menús (Problema de la Dieta)

Proyecto desarrollado para la asignatura de Investigación de Operaciones. Consiste en una herramienta analítica que calcula la combinación exacta de alimentos para cumplir con requerimientos nutricionales específicos al **menor costo económico posible**.

## 📌 Características Principales
* **Motor Matemático:** Utiliza Programación Entera Mixta (MILP) para garantizar porciones de comida reales y cuantificables.
* **Lógica de Optimización:** Implementado en Python utilizando la librería `PuLP`.
* **API REST:** Arquitectura Backend-Frontend separada mediante Flask y CORS.
* **Flexibilidad:** Calcula el óptimo basándose en mínimos (Calorías, Proteínas, Carbohidratos) y máximos (Grasas).

## 🛠️ Stack Tecnológico
* **Backend:** Python 3, Flask, PuLP, Pandas.
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API).
